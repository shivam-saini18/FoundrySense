# FoundrySense — Induction Furnace M&V Chain Demo

**FoundrySense** is an end-to-end Measurement & Verification (M&V) prototype demonstrating real-time heat-state detection, idle/overshoot alerting, and Scope 2 emissions tracking for induction foundries.

> **Simulation & Data Disclosure:** All telemetry streams and furnace heat cycles in this repository are **synthetic data** generated by the included deterministic M&V engine (30-run simulation median on synthetic telemetry). This repository demonstrates the complete data-to-dashboard M&V chain.

## Headline Benchmarks (30-Run Simulation Median)
* **Specific Energy Saving:** 31.6 kWh/t
* **Annualized Cost Savings:** ₹5.55 L/yr
* **Emissions Reduction:** 54 tCO₂/yr
* **Estimated Payback:** ~6.3 months

## Cost Architecture
* **Prototype Build Cost:** Near-zero software cost (built on open-source & free tiers)
* **Estimated Scale Cost:** ₹1.6 L hardware sensor kit + ₹2,500/month cloud & telemetry operations
